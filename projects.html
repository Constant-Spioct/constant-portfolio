LEARNING PROJECTS

Exploring ideas through practice.

These are selected demonstration projects created to explore data analysis concepts and develop practical skills. They are separate from my actual data-analysis projects listed above.

i

Illustrative learning concepts, not completed projects. The examples below are separate from the seven data-analysis projects listed above.

01 / CONCEPT

DATA EXPLORATION

Student Performance Analysis

Explore a sample academic dataset to look for patterns in study habits and assessment results. A concept for practising data cleaning, comparison, and responsible interpretation.

  • Python
  • Pandas
  • Matplotlib
View project details ↗

Learning goals: Explore a dataset, handle missing values, compare distributions, and present observations with appropriate context.

Suggested next step: Use an open, anonymised dataset. Avoid identifying individual students or implying that correlation proves causation.

02 / CONCEPT

DATA VISUALISATION

Sales Data Dashboard

Imagine a compact dashboard that summarises sample sales by month and category, making it easier to spot changes and ask useful follow-up questions.

  • Excel
  • SQL
  • Chart.js
View project details ↗

Learning goals: Practise summarising tabular data, selecting readable chart types, and designing a clear information hierarchy.

Suggested next step: Build an interactive prototype with sample data and annotate the limits of each metric.

03 / CONCEPT

WEB APPLICATION

Personal Expense Tracker

A learning concept for recording sample expenses and grouping them by category. It brings simple interface design together with practical data organisation.

  • HTML
  • CSS
  • JavaScript
View project details ↗

Learning goals: Practise form handling, input validation, data structures, and meaningful summaries.

Suggested next step: Use fictional entries for a demo. Personal financial details should not be published in a public portfolio.
